# Software License Request Process (v2.0 — Effective February 1, 2026)

This document describes the current, authoritative process for requesting a
software license for internal tools.

## Step 1: Submit a Request
Employees submit a software request through the Software Request Portal
(https://software.internal.example.com). The request must include:
- Employee ID
- Software name and edition requested
- Business justification
- Requested license duration (temporary or permanent)

## Step 2: Manager Approval
The employee's direct manager must approve the request within the portal.
Requests without manager approval are automatically closed after 5 business
days.

## Step 3: Procurement Review (for premium/paid software only)
If the requested software is classified as **premium** (a paid license with
a per-seat cost), the request is routed to the **Procurement Lead** for
budget approval. Free or already-licensed internal tools do not require
this step.

## Step 4: Provisioning
Once approved, the IT Operations team provisions the license within
2 business days. The employee receives an email confirmation with
activation instructions and an expiration date, if applicable.

## Required Supporting Information
- Manager's name and email
- Business justification (minimum 1 sentence)
- Cost center, for premium software
- For premium software: a completed Software Budget Justification Form
