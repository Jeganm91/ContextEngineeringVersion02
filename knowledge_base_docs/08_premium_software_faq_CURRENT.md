# Premium Software — Quick FAQ

A few common questions about premium (paid) software licenses, answered
briefly for employees who do not want to read the full policy document.

**Q: Who approves premium software requests?**
A: Your manager, plus someone from Procurement.

**Q: How often does a premium license need to be renewed?**
A: Premium licenses are typically renewed every **6 months** and must be
requested again after that if still needed.

**Q: Can I get an exception to the approval process?**
A: Talk to your manager first; exceptions are handled case by case.

This FAQ is maintained by the IT Helpdesk for quick reference and has not
been reviewed against the formal Premium Software Approval Policy recently.
