# Premium Software Approval Policy (v2.1 — Effective January 15, 2026)

Premium software licenses (any tool with a per-seat or per-user cost)
require approval from the **Procurement Lead**, in addition to standard
manager approval.

## Approval Chain for Premium Software
1. Employee submits the request via the Software Request Portal.
2. Manager approves the business justification.
3. **Procurement Lead** reviews and approves the cost, seat count, and
   budget code for the license.
4. License utilization is reviewed for renewal every **12 months** unless
   flagged for early review.

## Required Supporting Documentation
- Software Budget Justification Form
- Cost center
- Estimated number of seats required

This policy is the sole authoritative source for premium software approval
as of the effective date above. It supersedes any prior policy referencing
Finance Manager approval for premium software.
