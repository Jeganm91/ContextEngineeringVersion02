# Software License Request Process (v1.0 — Effective April 10, 2023)

**This version is deprecated. Refer to the current Software License Request
Process (v2.0) instead.**

Employees request software by emailing itrequests@example.com with the
software name and their Team Lead's approval. The Team Lead's approval is
sufficient for all software, including premium (paid) tools. IT reviews
requests weekly and provisions approved software within 5 business days.

No formal budget justification form was required under this version of the
process.
