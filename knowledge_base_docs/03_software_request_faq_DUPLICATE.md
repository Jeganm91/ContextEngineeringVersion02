# How to Request Software — Employee FAQ

New employees often ask how to request a software license for internal
tools. Here is a quick summary of the current process.

Employees submit a software request through the Software Request Portal.
The request must include Employee ID, software name and edition requested,
business justification, and requested license duration temporary or
permanent.

The employee's direct manager must approve the request within the portal.
Requests without manager approval are automatically closed after 5 business
days.

If the requested software is classified as premium a paid license with a
per-seat cost, the request is routed to the Procurement Lead for budget
approval. Free or already-licensed internal tools do not require this step.

Once approved, the license is provisioned within 2 business days. The
employee receives an email confirmation with activation instructions and
an expiration date, if applicable.

You will also need manager's name and email, business justification
minimum 1 sentence, cost center for premium software, and for premium
software a completed Software Budget Justification Form.

For questions, contact your onboarding buddy or IT support.
