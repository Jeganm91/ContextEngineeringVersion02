# How to Request Software — Employee FAQ

New employees often ask how to get access to software tools. Here's a quick
summary:

1. Go to the Software Request Portal and submit a request.
2. Your manager needs to approve it.
3. If it's a paid/premium tool, there's an extra budget approval step with
   Procurement.
4. Once approved, IT sets it up, usually within a couple of days.

Make sure you include why you need the software (business justification)
when you submit the request, plus which tool and edition you need.

For questions, contact your onboarding buddy or IT support.
