# Premium Software Policy (v1.0 — Effective June 1, 2022)

**This version is deprecated. Refer to the current Premium Software
Approval Policy (v2.1) instead.**

Paid software licenses require approval from the employee's Finance
Manager. There is no separate Procurement Lead review under this version.
License renewal timing was handled informally, on a case-by-case basis,
with no fixed review cycle.
